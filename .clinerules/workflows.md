## Project Workflows

Follow the workflows documented in `docs/workflows/`:

- **Issue Resolution:** `docs/workflows/issue-resolution-workflow.md`
  - Use `/create-issue` for exploring and documenting issues
  - Use `/fix-issue` for implementing backlog issues
  - Use `/resolve-ci` for finalizing PRs and CI monitoring

- **Git Workflow:** `docs/workflows/git-workflow.md`
- **PR Workflow:** `docs/workflows/pr-workflow.md`
- **Build Workflow:** `docs/workflows/build-workflow.md`

### Key Principles:
- All changes through feature branches and PRs
- PRs start as drafts, marked ready after author review
- One issue = one branch = one PR
