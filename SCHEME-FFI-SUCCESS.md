## Technical Details

### Scheme Code (`lib/Dialect/Hipsr/Scheme/print-operation.scm`)

```scheme
(define (print-operation op-name num-operands num-results generic-form)
  (display "Operation: \"")
  (display op-name)
  (display "\"\n")
  (display "  Operands: ")
  (display num-operands)
  (display "\n")
  (display "  Results: ")
  (display num-results)
  (display "\n")
  (display "  Generic form: ")
  (display generic-form)
  (display "\n\n"))
```

### C++ FFI Call (`lib/Dialect/Hipsr/Scheme/SchemeRuntime.cpp`)

```cpp
void printOperation(const char* opName, int numOperands, 
                    int numResults, const char* genericForm) {
  if (!scheme_initialized || !g_print_operation)
    return;

  // Build argument list: (list opName numOperands numResults genericForm)
  ptr args_list = Scons(Sstring(opName),
                  Scons(Sinteger(numOperands),
                  Scons(Sinteger(numResults),
                  Scons(Sstring(genericForm), Snil))));

  // Call Scheme: (apply print-operation args_list)
  ptr apply_proc = Stop_level_value(Sstring_to_symbol("apply"));
  Scall2(apply_proc, g_print_operation, args_list);
}
```

## Key FFI Functions Used

- **`Sstring(const char*)`** - Convert C string → Scheme string
- **`Sinteger(iptr)`** - Convert C integer → Scheme integer
- **`Scons(car, cdr)`** - Build cons cell (linked list)
- **`Snil`** - Empty list constant `'()` = `((ptr)0x26)`
- **`Scall1(proc, arg)`** - Call Scheme procedure with 1 argument
- **`Scall2(proc, arg1, arg2)`** - Call Scheme procedure with 2 arguments
- **`Stop_level_value(symbol)`** - Get top-level binding
- **`Sstring_to_symbol(name)`** - Create symbol from string

## Lessons Learned

1. **Boot file order matters**: petite.boot MUST be registered before scheme.boot
2. **Scall0-3 only**: No `Scall4` - use `apply` with list for 4+ arguments
3. **Snil not exported**: Must define as macro `#define Snil ((ptr)0x26)`
4. **eval needs 1 arg**: `Scall1(eval, expr)` uses top-level environment
5. **List construction**: Build from right-to-left with `Scons(..., Snil)`
