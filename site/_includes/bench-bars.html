Inline SVG built from _data/benchmarks.yml rather than a charting library: the internal appliance cannot be relied on to reach a CDN, vendoring a library to draw sixteen rectangles is not a trade worth making, and a committed image file would drift from the data the moment a snapshot is refreshed. This way the chart and the table underneath it cannot disagree. Takes no parameters. It renders nothing at all when the snapshot is a placeholder -- a bar chart of zeros is sixteen empty rows that read as a measurement of zero. The guard lives here rather than at the call site so that a second caller cannot forget it. Prose that points at the chart ("the chart above") has to carry the same guard itself, though; the call site in docs/benchmarks/index.md does. The table below the chart is the accessible version of the same data, which is why the SVG carries a summary rather than per-bar annotations. {%- endcomment -%} {%- assign snap = site.data.benchmarks.snapshot -%} {%- unless snap.placeholder -%} {%- comment -%} Column 1 of `prompt_lengths` is the 2048-token prompt, the length the matrix is characterised at and the one the showcase cards quote. So each row is turned into a fixed-width zero-padded key (TPS in hundredths, six digits) glued to its id, the whole lot is sorted as one string list, and the ids are read back out. Same pipe-delimited accumulator the pager in _layouts/docs.html uses, for the same reason: Liquid has no way to build an array element by element. Six digits caps the chart at 9999.99 tokens/s. Widen the pad if that ever stops being absurd. {%- endcomment -%} {%- assign keys = "" -%} {%- assign peak = 0 -%} {%- for row in site.data.benchmarks.lm -%} {%- assign v = row.tps[col] | times: 1.0 -%} {%- if v > peak -%}{%- assign peak = v -%}{%- endif -%} {%- assign padded = v | times: 100 | round | prepend: "000000" | slice: -6, 6 -%} {%- assign keys = keys | append: padded | append: "~" | append: row.id | append: "|" -%} {%- endfor -%} {%- assign ordered = keys | split: "|" | sort | reverse -%} {%- comment -%} Geometry, in viewBox units.
