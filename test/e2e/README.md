# E2E Integration Tests

End-to-end tests for the HIP EP MLIR compiler. These tests verify full compilation and deployment: `.mlir` → DLL → execution.

For build prerequisites and setup, see [docs/quick_start.md](../../docs/quick_start.md).

## Test Discovery

Tests are auto-discovered from `test/lit/e2e/*.mlir`. No manual CMake configuration needed.

## Running Tests

All commands assume you are in the project root (`onnx-hip-ep/`).
The build directory is `../build/onnx-hip-ep` by default.

```bash
# All E2E tests
ctest --test-dir ../build/onnx-hip-ep -R "^E2E_" --verbose

# Specific test
ctest --test-dir ../build/onnx-hip-ep -R "E2E_.*_test_conv_double_layer" --verbose

# Just compilation tests
ctest --test-dir ../build/onnx-hip-ep -R "^E2E_Compile_" --verbose

# Just execution tests
ctest --test-dir ../build/onnx-hip-ep -R "^E2E_Execute_" --verbose
```

## Test Structure

For each `.mlir` file in `test/lit/e2e/`, two CTest tests are created:

1. **E2E_Compile_{test_name}**: Compiles `.mlir` → `.dll` using `hip-compiler`
2. **E2E_Execute_{test_name}**: Loads and executes `.dll` using `hip-test`

**Example:**
- `test/lit/e2e/test_conv_double_layer.mlir` creates:
  - `E2E_Compile_test_conv_double_layer`
  - `E2E_Execute_test_conv_double_layer`

## Adding New Tests

1. Add new `.mlir` file to `test/lit/e2e/`
2. Reconfigure CMake (see [docs/quick_start.md](../../docs/quick_start.md))
3. Run tests: `ctest --test-dir ../build/onnx-hip-ep -R "^E2E_"`

No CMake editing required - tests are auto-discovered.

## Test Files

Test `.mlir` files are located in `test/lit/e2e/` and serve dual purposes:
- **LIT tests**: Verify MLIR pass transformations (via `// RUN:` directives)
- **E2E tests**: Verify full compilation and execution (via this CMakeLists.txt)

## Current Tests

Run `ctest --test-dir ../build/onnx-hip-ep -N -R "^E2E_"` to see all discovered E2E tests.

## Running with Real Runtime (GPU)

When the project is built with `-DBUILD_MOCK_RUNTIME=OFF`, the compiled DLLs
execute on a real AMD GPU. The execution tests require the ROCm shared libraries
to be in the system path.

**Windows (cmd):**
```cmd
set "THEROCK_DIST=D:\Develop\m\dist\therock"
set PATH=D:\Develop\m\dist\therock\bin;%PATH%
ctest --test-dir ..\build\onnx-hip-ep -R "^E2E_" --verbose
```

**Linux (bash):**
```bash
export THEROCK_DIST=/path/to/therock
export LD_LIBRARY_PATH=$THEROCK_DIST/lib:$LD_LIBRARY_PATH
ctest --test-dir ../build/onnx-hip-ep -R "^E2E_" --verbose
```

> **Note:** `THEROCK_DIST` must be set for both compile and execute tests.
> Compile tests need it so `hip-compiler` can find import libraries at link
> time. Execute tests need the ROCm DLLs in PATH to load the generated model
> DLL.

## Troubleshooting

**No tests found:**
- Verify `.mlir` files exist in `test/lit/e2e/`
- Reconfigure CMake with `--fresh` flag

**Compilation failures:**
- Check `hip-compiler` is built: `cmake --build ../build/onnx-hip-ep --target hip-compiler`
- Run compiler manually: `hip-compiler path/to/test.mlir -o test.dll`

**Execution failures:**
- Check `hip-test` is built: `cmake --build ../build/onnx-hip-ep --target hip-test`
- Check DLL was generated by compilation step
- Run manually: `hip-test path/to/test.dll --verbose --validate`

## Performance Testing

Use `onnxruntime_perf_test` to benchmark inference latency. The examples below
compare MorphiZen EP (AMD GPU via HIP) against DML EP.

### Setup

`onnxruntime_perf_test.exe` and `morphizen_config.json` are not installed by
default. Copy them into `../prebuilt-local/bin` before running:

```bash
cp ../build/onnxruntime/Release/Release/onnxruntime_perf_test.exe $PREBUILT_DIR/bin/
cp etc/morphizen_config.json $PREBUILT_DIR/bin/

export THEROCK_DIST=~/workspace/therock
export PATH="$THEROCK_DIST/bin:$PATH"
cd $PREBUILT_DIR/bin
```

### MorphiZen EP

```bash
./onnxruntime_perf_test.exe \
  --plugin_ep_libs "MorphiZenExecutionProvider|onnxruntime_morphizen_ep.dll" \
  --plugin_eps "MorphiZenExecutionProvider" \
  --plugin_ep_options "config_file|morphizen_config.json" \
  -t 60 -c 1 -s -I \
  /path/to/models/full_model_seq1.onnx
```

### DML EP

```bash
./onnxruntime_perf_test.exe \
  -e dml \
  -C "ep.dml.disable_graph_fusion|1" \
  -t 60 -c 1 -s -I \
  /path/to/models/full_model_seq1.onnx
```

### Key flags

| Flag | Description |
|------|-------------|
| `-t 60` | Run for 60 seconds |
| `-c 1` | 1 concurrent thread |
| `-s` | Show per-iteration latency statistics |
| `-I` | Use sequential inputs (do not randomize) |
