## morphizen-onnx-grep
`morphizen-onnx-grep` is a simple tool to debug and test your pattern matching

### Usage :
```
 morphizen-onnx-grep -f <onnx_model> -p <pattern_file> [-n <node_arg>] [-v] [-h]
```
`-f` <onnx_model> : onnx model file

`-p` <pattern_file> :  pattern file, can be json or python file

`-n` <node_arg> : node_arg name to trace ， checks whether a node matches pattern.
     If the `-n` option is omitted, the entire network will be traversed, and all nodes matching the pattern within the network will be matched.

`-v` verbose mode



### Sample with pattern is a json file
```
modphizen-onnx-grep.exe -f pt_reset50.onnx -p sample_pattern\conv_relu_maxpool.json -n 135

```

The pattern file can be generated by the `morphize-pattern-gen` tool.
